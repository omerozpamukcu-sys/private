# AORKing2 Windows paketi

Windows x86 EXE ve gerekli .NET çalışma zamanı ZIP dosyasına dahildir.

1. `AORKing2-Windows.zip` dosyasını indirip bir klasöre çıkar.
2. Yeni Rota kayıt ve Tedarik sekmelerini incelemek için `ArayuzuGor.cmd` dosyasını aç. Oyun ve pointer girişi gerekmez.
3. Normal masaüstü uygulaması için `BotuAc.cmd` dosyasını aç. Gerçek oyun bağlantısı güncel pointer/offset değerlerini gerektirir.

Tamir, ekipman dayanıklılığı 700 veya altına indiğinde tetiklenir. Slota dönüşte yalnızca mevcut tedarik turu sonlanır ve atak başlar; otomatik tedarik açıksa açık kalır.

Windows yayını ve 46/46 saf mantık testi Linux bulut ortamında tamamlandı. Windows'ta açılış ve canlı NPC işlemleri henüz doğrulanmadı. Bu indirme dalı kaynak geliştirme dalından ayrı tutulmuştur.
